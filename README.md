# StringPlus

**s21_string** — учебный проект на языке C.  

Проект посвящён разработке собственной библиотеки для работы со строками, повторяющей функциональность стандартной библиотеки `string.h` и расширяющей её возможностями, включая функции `sprintf`, `sscanf` и дополнительные утилиты для обработки строк.  

## Реализованные возможности

- реализация основных функций библиотеки `string.h` (копирование, конкатенация, поиск, сравнение, работа с памятью);  
- частичная и полная реализация функций `sprintf` и `sscanf` с поддержкой форматов и флагов;  
- дополнительные функции для работы со строками: `to_upper`, `to_lower`, `insert`, `trim`;  
- покрытие unit-тестами с использованием Check (≥ 80% функций);  
- сборка проекта через Makefile с целями: `all`, `clean`, `test`, `s21_string.a`, `gcov_report`.  

## Technologies

- C11  
- POSIX.1-2017  
- Check (unit-тесты)  
- Makefile  
- GCC
